# 용어집

- **커밋(commit)**: 변경 묶음의 스냅숏. 부모 커밋을 가리키는 해시로 이어진다
- **브랜치(branch)**: 특정 커밋을 가리키는 이동 가능한 포인터
- **HEAD**: 지금 체크아웃한 브랜치(또는 커밋)를 가리키는 포인터
- **원격(remote)**: 다른 곳에 있는 같은 저장소. 기본 이름은 origin
- **fetch**: 원격의 새 커밋을 받아 원격 추적 브랜치만 갱신한다
- **pull**: fetch 한 뒤 현재 브랜치에 병합한다
- **PR(Pull Request)**: 브랜치의 변경을 main 에 합쳐 달라는 요청. 본문의 Closes #번호로 이슈와 연결한다
- **리뷰(review)**: PR 의 변경을 읽고 질문·제안·승인을 남기는 일
- **충돌(conflict)**: 두 브랜치가 같은 곳을 다르게 바꿔 Git 이 자동으로 합치지 못한 상태
- **revert**: 지정한 커밋의 변경을 되돌리는 새 커밋을 만든다
